How it works

  1. Find your .xpl preset files (on the Force / MPC they are in MPC Documents / Plugin Presets, in the plugin's folder).
  2. Put them in one .zip and name it by the rules next to this. No time? Drop it anyway: the page shows the name it will use and lets you fix it.
  3. Drop the zip in the box, check the details, tick the box, press Send.
  4. I try it on a Force. If it is good it goes on the list below with your name and a download button.

Naming rules

  • A pack of presets: AUTHOR-PACK NAME.zip
    e.g. Sam-Dark Drones.zip
  • One preset: PRESET NAME-TYPE.zip
    e.g. Warm Wall-Pad.zip
  • TYPE is one of the usual preset-bank types below. If none fits, use Experimental.
  • Use a single dash - between the parts and none inside them. Apostrophes and slashes are dropped.
  • Inside the zip: only .xpl presets, plus an optional .txt or .md readme. Up to 8 MB.
